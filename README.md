# Abhishek's Ubuntu Portfolio

An interactive portfolio website that mimics an Ubuntu desktop interface.

## 🚀 Live Demo
Host on GitHub Pages: `https://aeron-gh.github.io/portfolio-un/`

## Features

- **Ubuntu Boot Screen** - Animated loading screen on page load
- **Desktop Interface** - Wallpaper, icons, dock, and top bar
- **Window Manager** - Draggable, resizable, closable windows
- **File Manager** - Browse folders like Nautilus
- **Terminal** - Interactive command line with custom commands
- **Text Editor** - View file contents

## Terminal Commands

Try these commands in the terminal:

| Command | Description |
|---------|-------------|
| `help` | Show all commands |
| `about` | About me |
| `skills` | My technical skills |
| `projects` | View my projects |
| `contact` | How to reach me |
| `neofetch` | Fun system info |
| `github` | Open my GitHub |
| `ls` | List files |
| `cat [file]` | Display file contents |
| `clear` | Clear terminal |

## Customization

### Update Your Info
Edit `js/main.js` to update:
- `FileContents.about` - Your bio
- `FileContents.skills` - Your skills
- `FileContents.contact` - Your contact info
- `FileSystem.structure` - Your projects/links

### Change Wallpaper
Edit `js/desktop.js` - `backgrounds` array with your preferred images.

## Hosting on GitHub Pages

1. Create a new repository on GitHub
2. Push this code to the repository
3. Go to Settings → Pages
4. Select "main" branch and save
5. Your portfolio will be live at `https://aeron-gh.github.io/portfolio-un/`

## Tech Stack

- Pure HTML, CSS, JavaScript
- No build tools required
- Google Fonts (Ubuntu)
